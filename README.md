# ruby_basic_projects

Four mini-projects using ruby to solve beginner CS problems.

## Stock picker:

A method that takes an array of prices happening over a series of days to determine the best time to buy and the best time to sell.
For example, if we enter [46, 32, 54, 64, 37], stock_picker will tell us to buy on day 2 and sell on day 4 for a profit of 32. If no profitable trades are possible, stock_picker will let us know.
