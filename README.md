# ruby_basic_projects

Four mini-projects using ruby to solve beginner CS problems.

## Stock picker:

A method that takes an array of prices happening over a series of days to determine the best time to buy and the best time to sell.
For example, if we enter [46, 32, 54, 64, 37], stock_picker will tell us to buy on day 2 and sell on day 4 for a profit of 32. If no profitable trades are possible, stock_picker will let us know.

## Caesar's Cipher:

When given a string, this method returns a string with all letters shifted forward or backwards by a given value.
The cipher wraps around the alphabet, so a Caesar's Cipher that shifts values forward y 3 would turn a 'Z' to a 'C'.
The cipher ignores non-letter characters as it converts the string.

## Substrings:

Given a string (sentence) and a dictionary (list of words), this method will return how many times the dictionary words could be used as substrings in the words of the sentence.
This method won't necessary work accuratey if there are any repeated letters in the dictionary words or the words of the sentence.

## Bubble Sort:

A basic sorting algorithm that sorts an array of numbers from lowest to highest by comparing adjacent numbers two at a time.
